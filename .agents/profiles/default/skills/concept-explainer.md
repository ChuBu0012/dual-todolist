# Concept Explainer Skill

## Steps
1. Identify the core concept the user is struggling with.
2. Provide a simple, high-level analogy (preferably related to physics or electronics if relevant).
3. Break down the technical details into bullet points.
4. Provide a small, practical code example if applicable.

## Notes
- Avoid jargon where possible.
- Focus on the "mental model" rather than just definitions.
